# Private Shopping Agent

Finished static landing page for the Private Shopping Agent consumer product.

## Included
- `private-shopping-agent.html`
- Responsive privacy-first shopping product page
- Light/dark theme toggle
- Feature, workflow, pricing, and FAQ sections

## Deployment
1. Upload the HTML file to your host.
2. Rename to `index.html` if needed.
3. Replace the email CTA with your live checkout link.

## Product
Private Shopping Agent is a one-time purchase consumer app for privacy-first product discovery, comparison, and buying decisions.
